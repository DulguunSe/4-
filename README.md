## №18 · Зүүн гарын дасгал: A S D F ба G

| Хуудас | Агуулга | Хэвлэх |
|---|---|---|
| 1 | Ээлжит хичээлийн төлөвлөгөө (хөтөлбөрийн 6 үе шат, мэдлэг/чадвар/хандлага) | 1 хувь |
| 2 | Туслах материал: асуудал дэвшүүлэх яриа, «Багш хэлнэ — хуруу дарна» жагсаалт, түгээмэл алдаа, хариу | 1 хувь |
| 3 | Зүүн гарын схем — A S D F G тодруулсан гар, хуруу бүрийн товч, 3 дүрэм | Сурагч бүрт, **хэвтээ, өнгөөр** |
| 4 | Ажлын хуудас (5 даалгавар) | Сурагч бүрт |
| 5 | 1 минутын сорилт, ахицын хүснэгт (№17–23), өөрийн үнэлгээ | Сурагч бүрт |

№17-ийн цаасан гарыг (3-р хуудас) энэ хичээлд дахин ашиглана.

## №17 · Гарын 10 хурууны зөв байрлал

Багшийн төлөвлөгөө, туслах материал ба хариу, өнгөт цаасан гар (Монгол кирилл ФЦУЖЭН байрлал, латин үсэг, хурууны дугаартай), 2 ажлын хуудас, будах цаасан гар.

## Дахин үүсгэх

```
NODE_PATH=$(npm root -g) node source/lesson17.js
NODE_PATH=$(npm root -g) node source/lesson18.js
```
