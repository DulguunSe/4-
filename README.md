# Гарын 10 хурууны зөв байрлал — 4-р анги

Компьютергүй, 40 минутын хичээлийн хэвлэх материал: **[gar-10-huruu-4-angi.pdf](gar-10-huruu-4-angi.pdf)** (A4, 6 хуудас).

| Хуудас | Агуулга | Хэвлэх |
|---|---|---|
| 1 | Багшийн хуудас — хичээлийн төлөвлөгөө (5 үе шат, 40 мин) | 1 хувь |
| 2 | Багшийн хуудас — дасгал, шүлэг, тоглоом, «Багш хэлнэ — хуруу дарна» жагсаалт, хариу | 1 хувь |
| 3 | Цаасан гар (өнгөт, бодит хэмжээтэй ойролцоо), гарын зураг, 3 алтан дүрэм | Сурагч бүрт, **хэвтээ, өнгөөр** |
| 4 | Ажлын хуудас 1 — «Миний 10 хуруу» | Сурагч бүрт |
| 5 | Ажлын хуудас 2 — «Аль хуруугаар дарах вэ?», зөв суулт, өөрийгөө үнэлэх | Сурагч бүрт |
| 6 | Нэмэлт — будах цаасан гар (хар цагаан хэвлэгчид) | Шаардлагатай бол |

Гар нь Монгол кирилл (ФЦУЖЭН) байрлалтай, товч бүр дээр латин үсэг болон хурууны дугаар (1 эрхий … 5 чигчий) бий.

Дахин үүсгэх: `NODE_PATH=$(npm root -g) node source/build.js` (Playwright + pypdf шаардлагатай).
